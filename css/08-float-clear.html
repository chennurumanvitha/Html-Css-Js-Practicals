CSS PRACTICAL 08

Float and Clear

Demonstration of CSS float and clear properties for controlling the layout of elements.

Objective

To demonstrate the use of CSS float and clear properties to control the positioning and flow of elements on a webpage.

Float Left

float: left

The float property moves an element to the left side of its container and allows other content to flow around it.

Float Left

This text flows around the element that has been floated to the left. The remaining content occupies the available space beside the floated element.

Float Right

float: right

The float property can also move an element to the right side of its container.

Float Right

This text flows around the element that has been floated to the right. The float allows the surrounding content to use the available space.

Clear Property

clear: both

The clear property prevents an element from appearing beside floated elements. The clear: both value clears both left and right floats.

Float with Text Content

Floated Element

The float property is commonly used to place images or other elements beside text. When an element is floated, the surrounding content flows around it.

In this example, the blue box is floated to the left while the paragraph content flows around the floated element.
