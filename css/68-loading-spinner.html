CSS Loading Spinner

Creating a loading spinner animation using CSS

Objective

To create a loading spinner animation using CSS @keyframes and the animation property without using JavaScript.

Loading Spinner Animation

The spinner is created using CSS borders and a circular shape. The @keyframes rule continuously rotates the spinner from 0 to 360 degrees.

CSS Keyframe Code

.spinner { width: 75px; height: 75px; border: 8px solid #dbeafe; border-top: 8px solid #2563eb; border-radius: 50%; animation: spin 1s linear infinite; } @keyframes spin { from { transform: rotate(0deg); } to { transform: rotate(360deg); } }
