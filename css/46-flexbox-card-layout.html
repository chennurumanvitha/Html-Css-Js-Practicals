Flexbox Features Used

display: flex

Creates a Flexbox container for arranging child elements efficiently.

flex-wrap

Allows cards to move to the next line when there is not enough horizontal space.

gap

Adds consistent spacing between the cards without using individual margins.

flex

Controls how each card grows and adapts to the available space.
