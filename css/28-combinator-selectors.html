CSS Combinator Selectors

Demonstrating descendant, child, adjacent sibling, and general sibling selectors

Objective

To create a webpage demonstrating CSS combinator selectors including descendant, child, adjacent sibling, and general sibling selectors.

Combinator Selectors

1. Descendant Selector

.parent p

Selects all matching elements that are anywhere inside the specified parent element.

Descendant Example

This paragraph is inside a descendant element.

2. Child Selector

.parent > p

Selects only the elements that are direct children of the specified parent.

Child Example

This paragraph is a direct child.

This paragraph is a nested child.

3. Adjacent Sibling

h4 + p

Selects the first matching sibling element that immediately follows another element.

Adjacent Sibling Example

This paragraph immediately follows the heading.

This paragraph is not immediately after the heading.

4. General Sibling

h4 ~ p

Selects all matching sibling elements that appear after the specified element.

General Sibling Example

This paragraph is a sibling after the heading.

Another element between the siblings.

This paragraph is also selected.

CSS Combinator Examples

/* Descendant Selector */
.parent p { color: blue; }

/* Child Selector */
.parent > p { color: purple; }

/* Adjacent Sibling Selector */
h4 + p { color: green; }

/* General Sibling Selector */
h4 ~ p { color: red; }
