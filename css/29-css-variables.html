CSS PRACTICAL 29

CSS Variables

Demonstrating custom properties and the var() function

Objective

To create a webpage demonstrating CSS variables, also known as custom properties, and use them with the var() function.

CSS Variables Demonstration

Primary Color

--primary-color

Stores the main blue color used throughout the webpage.

Secondary Color

--secondary-color

Stores the darker blue color used for headings and buttons.

Border Radius

--radius

Stores a common border-radius value for reusable styling.

Using CSS Variables

This box uses the --primary-color variable
Button Using CSS Variables
:root {
  --primary-color: #2563eb;
  --secondary-color: #1e3a8a;
  --radius: 10px;
}

.demo-box {
  background: var(--primary-color);
  border-radius: var(--radius);
}

.demo-button {
  background: var(--secondary-color);
  border-radius: var(--radius);
}

CSS Variable Syntax

CSS variables are declared using a name beginning with two hyphens, such as --primary-color.

The var() function is then used to access the value of the custom property.

:root {
  --main-color: #2563eb;
}

element {
  color: var(--main-color);
}
