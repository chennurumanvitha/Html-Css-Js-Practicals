CSS Grid Template Areas

Designing webpage layouts using named grid areas

Objective

To create a structured webpage layout using CSS Grid Template Areas and named grid areas for header, sidebar, main content, aside, and footer sections.

Grid Template Areas Layout

CSS Grid Template Areas allow different parts of a webpage layout to be assigned meaningful names. These names are then arranged using the grid-template-areas property.

Header

Website Header Area

Sidebar

  • Dashboard
  • Profile

Main Content

This is the main content area of the webpage. It occupies the central grid area.

Grid Template Areas

The main area is assigned using grid-area: main;

Responsive Layout

The grid structure changes automatically on smaller screens using media queries.

  • Latest News
  • Announcements

Website Footer Area

Named Grid Areas

Header

The top section of the webpage is assigned to the header grid area.

Sidebar

The left navigation section is assigned to the sidebar grid area.

Main

The central content section is assigned to the main grid area.

Aside

The right-side information section is assigned to the aside grid area.

Footer

The bottom section is assigned to the footer grid area.

Responsive Design

Media queries rearrange the named areas for smaller screen sizes.
