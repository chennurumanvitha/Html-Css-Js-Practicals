CSS PRACTICAL 07

CSS Positioning

Demonstration of static, relative, absolute, fixed, and sticky positioning using CSS.

Objective

To demonstrate different CSS positioning properties including static, relative, absolute, fixed, and sticky.

Static Positioning

position: static

Static positioning is the default position of an HTML element. The element follows the normal flow of the webpage.

Static Position

Relative Positioning

position: relative

A relatively positioned element remains in the normal document flow but can be moved using top, bottom, left, or right properties.

Relative Position

Absolute Positioning

position: absolute

An absolutely positioned element is positioned relative to its nearest positioned ancestor.

Absolute Position

Fixed Positioning

position: fixed

A fixed element stays in the same position on the screen even when the webpage is scrolled.

Scroll the page to observe the fixed box.

Sticky Positioning

position: sticky

A sticky element behaves like a normally positioned element until a specified scroll position is reached.

Sticky Position

Scroll inside this box to see the sticky heading remain at the top.

CSS positioning allows developers to control where elements appear on a webpage.

The sticky element remains visible while scrolling within its container.

This is commonly used for navigation bars, headings, and other interface elements.

Continue scrolling to observe the effect.

Sticky positioning combines aspects of relative and fixed positioning.
