CSS PRACTICAL 73

clamp(), min() and max()

CSS functions for flexible and responsive layouts

Objective

To create a responsive webpage using the CSS clamp(), min(), and max() functions for flexible sizing and responsive layouts.

clamp() Function

Responsive Heading

The clamp() function allows a value to grow or shrink within a specified minimum and maximum range. It is useful for creating responsive typography without using many media queries.

min() Function

Flexible Width Using min()

The min() function selects the smallest value from the given values. This box uses min(700px, 90%), so its width never becomes larger than 700 pixels.

max() Function

Flexible Width Using max()

The max() function selects the largest value from the given values. This box uses max(300px, 70%), providing a minimum width while remaining responsive.

Combining clamp(), min() and max()

Responsive Content Box

This section combines all three CSS functions. The width uses min(), the padding uses max(), and the heading and paragraph use clamp(). This creates a flexible layout that adapts to different screen sizes.

CSS Functions

clamp()

clamp(min, preferred, max)

Keeps a value between a minimum and maximum while allowing it to respond to the available space.

min()

min(value1, value2)

Uses the smallest value from the supplied values.

max()

max(value1, value2)

Uses the largest value from the supplied values.
