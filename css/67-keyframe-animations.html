CSS Keyframe Animations

Creating animations using the CSS @keyframes rule

Objective

To create a webpage demonstrating CSS keyframe animations using the @keyframes rule and animation properties to create movement, rotation, scaling, fading, bouncing, and loading effects.

Moving Animation

The moving box continuously moves from the left side to the right side using a keyframe animation.

Move

Rotation Animation

The element rotates continuously from 0 degrees to 360 degrees.

Rotate

Scaling Animation

The element smoothly increases and decreases in size using the scale transformation.

Scale

Fade Animation

The opacity of the element changes continuously to create a fading effect.

Fade Effect

Bounce Animation

The circular element moves vertically to create a bouncing animation.

Bounce

Pulse Animation

The element continuously grows slightly and returns to its original size.

Pulse Effect

Loading Animation

A rotating circular loader can be created using CSS keyframes without JavaScript.
