CSS-Only Button Hover Animation

Create animated buttons using CSS hover effects.

Objective

To create animated button hover effects using only HTML and CSS, demonstrating CSS transitions, transforms, pseudo-elements, shadows, and hover states.

Button Hover Animations

Move the pointer over each button to see the CSS-only hover animation.

CSS Hover Animation Technique

.button {
    background: #2563eb;
    color: white;
    padding: 14px 28px;
    border: none;
    border-radius: 8px;
    transition: 0.3s ease;
}

.button:hover {
    background: #1e3a8a;
    transform: translateY(-5px);
    box-shadow: 0 8px 18px rgba(37, 99, 235, 0.3);
}
