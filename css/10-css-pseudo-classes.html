CSS Pseudo-Classes

Demonstrating :hover, :active, :focus, and :visited.

Objective

To create a webpage demonstrating CSS pseudo-classes such as :hover, :active, :focus, and :visited.

:hover Pseudo-Class

The :hover pseudo-class applies styles when the mouse pointer is placed over an element.

:active Pseudo-Class

The :active pseudo-class applies styles while an element is being clicked or activated.

:focus Pseudo-Class

The :focus pseudo-class applies styles when an input element receives keyboard or mouse focus.

:visited Pseudo-Class

The :visited pseudo-class changes the style of a link after the link has been visited.
