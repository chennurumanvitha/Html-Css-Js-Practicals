Dark Mode Webpage

Create a dark-mode webpage using CSS variables

Objective

To create a webpage that supports light and dark themes using CSS variables and JavaScript.

Dark Mode Webpage

CSS Variables and Dark Mode

Click the button in the navigation bar to switch between light mode and dark mode.

The complete webpage changes its background, cards, text, borders, and other colors.

CSS Variables Used for Dark Mode

Page Background

CSS variables control the background color of the complete webpage.

Card Background

Cards automatically change their background when dark mode is enabled.

Text Colors

Heading, paragraph, and muted text colors change according to the selected theme.

Light and Dark Theme

Light Theme

White background with dark text.

Dark Theme

Dark background with light text.
