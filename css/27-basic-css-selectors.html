CSS Selectors

Demonstration of universal, element, class, ID, attribute, and grouping selectors

Objective

To demonstrate different types of CSS selectors and understand how they are used to select and style HTML elements.

CSS Selector Examples

Universal Selector

The * selector is used at the beginning of the stylesheet to apply common styles to all elements.

Element Selector

The p selector styles all paragraph elements on the page.

Class Selector

A class selector begins with a dot and can be applied to multiple elements.

ID Selector

An ID selector begins with a hash symbol and targets a specific element.

Attribute Selector

Attribute selectors can target elements based on their attributes, such as input type.

Grouping Selector

Grouping selectors allow the same CSS rules to be applied to multiple selectors.
