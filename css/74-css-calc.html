CSS calc() Function

Create flexible layouts using calculated CSS values

Objective

To create a webpage demonstrating the CSS calc() function for calculating flexible widths, heights, spacing, font sizes, and responsive layouts.

calc() for Width

Calculated Width

This box uses width: calc(100% - 40px). The browser calculates the width by subtracting 40 pixels from the available width.

calc() for Spacing

Calculated Margin and Padding

The margin and padding of this box are calculated using the CSS calc() function.

calc() for Two-Column Layout

Main Content

This column uses calc(60% - 10px) to calculate its width.

Sidebar

This column uses calc(40% - 10px) to calculate its width.

calc() for Height

Calculated Height

Height: calc(40vh - 20px)

calc() for Font Size

Responsive Font Size

The heading uses calc(1.5rem + 1.5vw) to calculate its font size based on the viewport width.
