CSS Practical 01

Demonstration of Inline, Internal and External CSS

Dashboard CSS Programs

1. Objective

To create a webpage demonstrating the three methods of applying CSS: Inline CSS, Internal CSS, and External CSS.

2. Inline CSS

Inline CSS is applied directly to an HTML element using the style attribute.

Inline CSS Demonstration

This box is styled using CSS written directly inside the HTML element.

3. Internal CSS

Internal CSS is written inside the <style> element in the <head> section of an HTML document.

Internal CSS Demonstration

This box receives its styling from the internal CSS rules defined in the <style> section.

4. External CSS

External CSS is stored in a separate .css file and connected to the HTML page using the <link> element.

External CSS Demonstration

This box receives its styling from the external style.css file.

5. Comparison of CSS Types

Type Location Usage
Inline CSS Inside HTML element Styling a specific element
Internal CSS Inside <style> Styling one webpage
External CSS Separate .css file Styling multiple webpages
