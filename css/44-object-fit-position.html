CSS PRACTICAL 44

Object-Fit and Object-Position

Control image sizing, cropping, and positioning using CSS.

Objective

To demonstrate the use of CSS object-fit and object-position properties for controlling how images are resized, cropped, and positioned inside containers.

Object-Fit Demonstration

object-fit: fill

Stretches the image to completely fill the container.

object-fit: contain

Displays the complete image while maintaining its aspect ratio.

object-fit: cover

Covers the entire container while maintaining the image ratio.

object-fit: none

Displays the image at its original size without resizing.

Object-Position Demonstration

Top

object-position: top;

Center

object-position: center;

Bottom

object-position: bottom;

Left

object-position: left;

Right

object-position: right;

Custom Position

object-position: 75% 25%;
