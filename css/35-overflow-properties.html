CSS PRACTICAL 35

Overflow Properties

Demonstrating visible, hidden, scroll, and auto overflow using CSS

Objective

To demonstrate the CSS overflow properties and understand how content is handled when it exceeds the size of an element.

Overflow Properties

overflow: visible

Content is displayed outside the box when it exceeds its dimensions.

This box uses overflow: visible. Extra content can extend outside the fixed-height container. This demonstrates how visible overflow allows content to remain displayed.

overflow: hidden

Extra content is clipped and not displayed outside the box.

This box uses overflow: hidden. When the content becomes larger than the container, the extra content is clipped and cannot be seen.

overflow: scroll

Scrollbars are displayed so that hidden content can be accessed.

This box uses overflow: scroll. Scrollbars allow the user to move through content that does not fit inside the fixed-size container. More content is added here to demonstrate scrolling.

overflow: auto

Scrollbars appear automatically when they are needed.

This box uses overflow: auto. If the content exceeds the available space, the browser automatically provides the required scrollbar.

Horizontal Overflow

This content is wider than the container. Scroll horizontally to view the complete content.

Vertical Overflow

This container has a fixed height and uses overflow-y: auto.

Additional content creates vertical overflow. A vertical scrollbar appears automatically.

Overflow properties are useful when designing cards, panels, menus, tables, and other layouts.

The user can scroll through the content without changing the size of the main container.

Overflow Demonstration

CSS overflow controls what happens when the content inside an element is larger than its specified width or height.

In this example, the container has a fixed height and overflow: auto. When the content exceeds the available space, a scrollbar is provided.

This technique is useful for displaying long text inside cards and panels while keeping the layout organized.
