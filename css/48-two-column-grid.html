Two-Column Webpage Layout

A responsive two-column webpage layout created using CSS Grid for organizing main content and a sidebar.

Objective

To create a two-column webpage layout using CSS Grid, with a main content area and a sidebar that automatically changes to a single-column layout on smaller screens.

Two-Column Grid Layout

About CSS Grid

CSS Grid is a powerful layout system that allows web developers to arrange elements into rows and columns.

A two-column layout is commonly used for webpages where the main content appears on one side and additional information or navigation appears on the other side.

The grid-template-columns property controls the width of each column. In this example, the main column occupies twice the available space of the sidebar.

Layout Features

Main Content

The main column contains the primary information and occupies two parts of the available grid space.

Sidebar

The sidebar contains additional navigation links and occupies one part of the available space.

Grid Gap

The gap property creates consistent spacing between the two columns.

Responsive Design

A media query changes the two-column layout into a single-column layout on smaller screens.
