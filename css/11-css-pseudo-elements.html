CSS PRACTICAL 11

CSS Pseudo-Elements

Demonstrating ::before, ::after, ::first-letter, and ::first-line.

Objective

To create a webpage demonstrating CSS pseudo-elements such as ::before, ::after, ::first-letter, and ::first-line.

::before Pseudo-Element

CSS pseudo-elements can be used to insert content before an HTML element.

::after Pseudo-Element

CSS pseudo-elements can also insert content after an HTML element.

::first-letter Pseudo-Element

Pseudo-elements allow developers to style a specific part of an element without adding extra HTML elements. The first letter of this paragraph is styled differently.

::first-line Pseudo-Element

The first line of this paragraph has a different style. Resize the browser window to observe how the first line changes automatically according to the available space.
