2D and 3D CSS Transformations

Demonstrating two-dimensional and three-dimensional transformations

Objective

To create a webpage demonstrating 2D and 3D CSS transformations using properties such as translate(), rotate(), scale(), skew(), perspective, rotateX(), rotateY(), and rotateZ().

2D Transformations

CSS 2D transformations change the position, size, angle, or shape of an element along the horizontal and vertical axes.

Translate

Translate

Moves the element along the X and Y axes.

Rotate

Rotate

Rotates the element around its center.

Scale

Scale

Increases or decreases the size of the element.

Skew

Skew

Slants the element along its axes.

Combined 2D Transformation

Multiple transformation functions can be combined using the CSS transform property.

3D Transformations

CSS 3D transformations allow elements to be rotated and positioned in three-dimensional space using the X, Y, and Z axes.

Rotate X

rotateX()

Rotates the element around the X-axis.

Rotate Y

rotateY()

Rotates the element around the Y-axis.

Rotate Z

rotateZ()

Rotates the element around the Z-axis.
