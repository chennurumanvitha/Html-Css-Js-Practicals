Semantic HTML Elements

Creating Structured and Meaningful Web Pages Using HTML5 Semantic Elements

Objective

To create an HTML page demonstrating semantic elements such as <header>, <nav>, <section>, <article>, and <footer>.

1. Semantic HTML Elements

Semantic HTML elements clearly describe the meaning and purpose of the content they contain. They improve webpage structure, readability, accessibility, and maintainability.

<header>

Represents the introductory content of a webpage or a particular section.

<nav>

Contains important navigation links used to move between webpages or sections.

<section>

Groups related content into a meaningful section of a webpage.

<article>

Represents independent content such as an article, blog post, or news item.

<footer>

Contains footer information such as copyright, contact information, or links.

5. Advantages of Semantic HTML

  • Improves webpage structure and readability.
  • Makes the content easier to understand for developers.
  • Improves accessibility for users and assistive technologies.
  • Helps search engines understand the structure of webpage content.
  • Makes websites easier to maintain and update.
