CSS PRACTICAL 13

Responsive Webpage

Demonstration of responsive web design using CSS media queries

Objective

To create a responsive webpage using CSS media queries that adjusts its layout and appearance according to different screen sizes.

1. Responsive Web Design

Responsive web design allows a webpage to automatically adjust its layout, text, and content according to the size of the device screen.

Desktop

On larger screens, the cards are displayed side by side.

Tablet

The layout adjusts to provide comfortable viewing on medium-sized screens.

Mobile

On smaller screens, the cards are displayed vertically.

2. CSS Media Query

A media query is a CSS feature used to apply different styles depending on screen size, device characteristics, or other conditions.

Desktop: Cards are displayed horizontally.

Mobile: Cards are displayed vertically.

Media Query: @media (max-width: 700px)

3. Responsive Layout Demonstration

Resize the browser window to observe how the webpage changes its layout. On screens smaller than 700 pixels, the cards change from a row layout to a column layout.

Responsive Features

  • Flexible card layout
  • Responsive navigation
  • Adjustable heading size
  • Mobile-friendly spacing
  • Responsive buttons
