HTML5 Input Types

Using Modern HTML5 Form Input Elements

Objective

To create a webpage using HTML5 input types such as email, date, number, and password.

1. HTML5 Input Types Demonstration

HTML5 provides several input types that make forms easier to use and provide built-in browser validation. The following form demonstrates email, date, number, and password input types.

2. HTML5 Input Types Used

The following HTML5 input types are demonstrated in the form above.

Email Input

The type="email" input is used to collect an email address and provides basic browser validation.

Date Input

The type="date" input allows the user to select a date using a browser date picker.

Number Input

The type="number" input is used to enter numerical values. The minimum and maximum values can be specified.

Password Input

The type="password" input hides the characters entered by the user.
