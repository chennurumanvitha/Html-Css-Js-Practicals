Frames & Iframes

Demonstrating Frames and Iframes in HTML

Objective

To create a webpage using frames and iframes to display and embed content within a webpage.

1. Frames Concept

Frames were traditionally used to divide a browser window into multiple sections. Each section could display a different HTML document.

Frame 1

Displays the first webpage.

Frame 2

Displays the second webpage.

Example of the traditional frame syntax:

<frameset cols="50%,50%">
  <frame src="page1.html">
  <frame src="page2.html">
</frameset>

Note: The <frameset> and <frame> elements are obsolete in HTML5. They are shown here as a syllabus/ educational example.

2. Iframe Demonstration

An iframe is the modern HTML element used to embed another webpage or document inside the current webpage.
