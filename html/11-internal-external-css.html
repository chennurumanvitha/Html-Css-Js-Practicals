Internal and External CSS

Creating a Styled Webpage Using Internal and External CSS Techniques

Objective

To create an HTML webpage and demonstrate different methods of applying CSS, with special focus on internal CSS and external CSS styling.

Introduction to CSS

CSS stands for Cascading Style Sheets. It is used to control the appearance, layout, colors, spacing, fonts, and overall presentation of HTML elements.

CSS can be applied to an HTML document in three main ways: inline CSS, internal CSS, and external CSS.

Inline CSS

CSS is written directly inside the style attribute of an HTML element.

Internal CSS

CSS rules are written inside the <style> element in the HTML document's <head>.

External CSS

CSS rules are stored in a separate .css file and connected to HTML using the <link> element.

Comparison of CSS Methods

CSS Method Location Suitable For
Inline CSS Inside the HTML element Individual element styling
Internal CSS Inside the <style> element Single webpage
External CSS Separate .css file Multiple webpages

Advantages of Using CSS

  • Separates webpage content from presentation.
  • Improves consistency across webpages.
  • Makes webpages easier to maintain.
  • Provides better control over layout and design.
  • External stylesheets can be reused on multiple pages.
  • Helps create responsive and user-friendly webpages.
