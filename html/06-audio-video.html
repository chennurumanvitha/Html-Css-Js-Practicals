Audio & Video

Creating Multimedia Content Using HTML

Objective

To create a webpage using HTML audio and video elements with appropriate controls and multimedia content.

1. Audio Element

The <audio> element is used to embed sound or music into a webpage. The controls attribute provides playback controls such as play, pause and volume.

2. Video Element

The <video> element is used to display video content on a webpage. The controls attribute provides video playback controls.
