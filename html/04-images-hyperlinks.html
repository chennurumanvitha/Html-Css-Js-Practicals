Objective

To create an HTML webpage containing images and hyperlinks using appropriate HTML elements.

1. Images in HTML

Images can be added to a webpage using the <img> element. The src attribute specifies the image location, while the alt attribute provides alternative text.

2. Hyperlinks in HTML
