Dependent Dropdown

Country → State → City using JavaScript

Objective

To create dependent dropdown menus where the available states depend on the selected country and the available cities depend on the selected state.

Interactive Demonstration

Select a country to load its states. Then select a state to load its cities.

Please select a country, state and city.
