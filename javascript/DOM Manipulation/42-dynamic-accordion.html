Create an interactive accordion using JavaScript

Objective

To create an interactive accordion using JavaScript DOM manipulation, where clicking a heading displays or hides its corresponding content.

Interactive Demonstration

Click any heading to expand or collapse its content.

HTML is the standard markup language used to create the structure and content of webpages.
CSS is used to style webpages and control their layout, colors, fonts, spacing and responsive appearance.
JavaScript is a programming language that adds interactivity and dynamic behavior to webpages.
DOM manipulation allows JavaScript to access, modify, create and remove HTML elements dynamically.
