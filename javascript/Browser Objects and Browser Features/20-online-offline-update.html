This webpage listens for the browser's online and offline events. When the connection status changes, the information displayed on the page is updated automatically.

Waiting for a connection status change.

How It Works

The navigator.onLine property indicates whether the browser currently reports an online connection.

The online event is triggered when the browser detects a connection, while the offline event is triggered when the browser detects that it is offline.
