Demonstrating the Geolocation API using JavaScript

Objective

To demonstrate browser geolocation using the JavaScript Geolocation API and obtain the user's current geographical position after permission is granted.

How It Works

The browser provides the navigator.geolocation object for accessing location information.

The getCurrentPosition() method requests the user's current geographical position. The browser may ask the user for permission before providing the location.

Privacy: Location access is permission-based. The browser controls whether the webpage is allowed to receive the location.
