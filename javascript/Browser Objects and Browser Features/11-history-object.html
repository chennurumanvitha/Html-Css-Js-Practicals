History Object

Demonstrating browser history navigation using JavaScript

Objective

To demonstrate the JavaScript History object and use its properties and methods to navigate through browser history.

Browser History Information

History Length

0

Current Page

1
Note: The Back and Forward buttons use the browser's actual session history. Their effect depends on the pages you have visited in the current browser session.

History Object Methods

JavaScript provides the following commonly used methods through the history object:

history.back()

Moves the browser back by one page in the session history.

history.forward()

Moves the browser forward by one page in the session history.

history.go()

Moves a specified number of steps through the session history.

history.length

Returns the number of entries in the current session history.
