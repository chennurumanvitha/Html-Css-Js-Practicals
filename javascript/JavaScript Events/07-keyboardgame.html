Keyboard-Controlled Game

Control a character using keyboard events

Objective

To demonstrate keyboard events by creating an interactive webpage/game where a player is controlled using keyboard keys.

Keyboard-Controlled Game

Move the blue player to the green target using the Arrow Keys or W, A, S, D.

Controls: ↑ W = Up   |   ↓ S = Down   |   ← A = Left   |   → D = Right
P
Game Status

Click inside the game area and press a movement key.

Last Key: None

Player Position: 20, 20
