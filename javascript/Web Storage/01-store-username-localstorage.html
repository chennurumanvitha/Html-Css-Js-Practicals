Store Username using localStorage

Save and retrieve a username using browser localStorage

Objective

Create a JavaScript program that accepts a username from the user and stores it in the browser's localStorage.

Username Storage

Saved Username

No username saved

How It Works

1. The user enters a username into the input field.

2. JavaScript stores the username in localStorage.

3. The saved username is displayed on the page.

4. The data remains available even after refreshing the webpage until it is removed.

Features

  • Accept a username from the user.
  • Store the username using localStorage.
  • Retrieve the stored username.
  • Display the saved username.
  • Clear the stored username.
  • Demonstrate persistent browser storage.
  • Responsive interface.
