Practical 18

localStorage vs sessionStorage

Compare the two browser storage mechanisms

Objective

To compare localStorage and sessionStorage and demonstrate how data is stored and retrieved using both browser storage methods.

Storage Comparison

Feature localStorage sessionStorage
Storage Duration Data remains until it is removed. Data remains for the current browser tab session.
Scope Available across browser tabs for the same origin. Limited to the current tab or window.
Data Format Stores data as strings. Stores data as strings.
JavaScript API localStorage sessionStorage
Typical Use Preferences and persistent application data. Temporary data for a browser session.
