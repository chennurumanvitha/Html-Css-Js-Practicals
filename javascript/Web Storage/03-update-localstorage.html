Update Data in localStorage

Update previously stored data using JavaScript

Objective

Create a JavaScript program that retrieves a username stored in localStorage and allows the user to update the stored value.

Update Stored Username

Current Username

No username stored

How It Works

Step 1: Retrieve the existing username using localStorage.getItem().
Step 2: Enter a new username in the input field.
Step 3: Use localStorage.setItem() with the same key to replace the old value.
Step 4: Retrieve and display the updated value.

Features

  • Display the currently stored username.
  • Accept a new username.
  • Update data using localStorage.setItem().
  • Retrieve the updated data.
  • Handle cases where no username is stored.
  • Demonstrate persistent browser storage.
  • Responsive interface.
