Currency Converter

Convert currencies using a live exchange-rate API

Objective

Create a currency converter that retrieves exchange rates from an API and converts an amount from one currency into another.

API Information

Frankfurter Exchange Rates API

This project uses the Frankfurter API to request exchange-rate data. JavaScript uses fetch() to send the API request and JSON data is used to calculate the converted amount.

Features

  • Convert between different currencies.
  • Retrieve exchange rates from an external API.
  • Use the JavaScript fetch() function.
  • Process API responses using JSON.
  • Swap source and target currencies.
  • Validate the entered amount.
  • Display the exchange rate and converted amount.
  • Handle API and network errors.
  • Reset the converter.
  • Responsive interface for different screen sizes.
