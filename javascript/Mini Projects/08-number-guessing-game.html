Number Guessing Game

Guess the randomly generated number using JavaScript

Objective

Create a number guessing game in which the computer generates a random number and the user tries to guess it.

Guess the Number

I have selected a number between 1 and 100.

Try to guess the number!

Attempts: 0

Features

  • Generates a random number from 1 to 100.
  • Accepts the user's number guess.
  • Indicates whether the guess is too high or too low.
  • Displays the number of attempts.
  • Detects the correct answer.
  • Allows the user to start a new game.
  • Press Enter to submit a guess.
  • Responsive design for different screen sizes.
