Notes Application

Create, edit, delete and save notes using localStorage

Objective

Create a notes application that allows users to create, edit, delete and permanently store notes in the browser using localStorage.

Create a Note

Saved Notes

No notes saved yet.

Features

  • Create new notes with a title and content.
  • Save notes using browser localStorage.
  • Notes remain available after refreshing the page.
  • Edit existing notes.
  • Delete individual notes.
  • Clear all saved notes.
  • Display the note creation/update date.
  • Automatically load saved notes when the page opens.
  • Responsive design for different screen sizes.
