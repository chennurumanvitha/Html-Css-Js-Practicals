Tic-Tac-Toe Game

Play the classic two-player game using JavaScript

Objective

Create an interactive Tic-Tac-Toe game where two players take turns placing X and O on a 3 × 3 game board.

Play Tic-Tac-Toe

Player X's Turn

Features

  • Interactive 3 × 3 Tic-Tac-Toe board.
  • Two-player gameplay.
  • Alternates between Player X and Player O.
  • Detects all winning combinations.
  • Detects a draw when the board is full.
  • Highlights the winning cells.
  • Prevents moves after the game ends.
  • New Game button to restart the game.
  • Responsive design for different screen sizes.
