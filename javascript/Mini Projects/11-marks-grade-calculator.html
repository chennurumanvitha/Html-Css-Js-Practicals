Student Marks & Grade Calculator

Calculate total marks, percentage and grade using JavaScript

Objective

Create a student marks calculator that accepts marks for different subjects and calculates the total, percentage, average and corresponding grade.

Features

  • Accepts student name and roll number.
  • Accepts marks for six subjects.
  • Validates marks between 0 and 100.
  • Calculates total marks.
  • Calculates percentage and average.
  • Assigns a grade based on percentage.
  • Displays individual subject marks.
  • Provides a reset button.
  • Responsive design for different screen sizes.
