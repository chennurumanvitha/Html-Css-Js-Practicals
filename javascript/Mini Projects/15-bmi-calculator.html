BMI Calculator

Calculate Body Mass Index using JavaScript

Objective

Create a BMI calculator that accepts height and weight, performs the BMI calculation using JavaScript, and displays the calculated BMI value.

How the Calculation Works

BMI Formula

BMI is calculated by dividing weight in kilograms by height in metres squared.

The program first converts the entered height from centimetres to metres and then performs the calculation.

Features

  • Accepts weight in kilograms.
  • Accepts height in centimetres.
  • Converts height into metres.
  • Calculates BMI using JavaScript.
  • Displays the BMI value to two decimal places.
  • Validates user input.
  • Provides a reset button.
  • Responsive interface for different screen sizes.

Important Note

BMI is a screening measurement, not a diagnosis. BMI interpretation for children and teenagers is different from adult interpretation and depends on factors such as age and sex. This educational project therefore displays the calculated BMI value without assigning adult weight categories.
